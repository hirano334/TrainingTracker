# Google Drive 同期の準備

アプリから自分の Google Drive に記録を保存・同期するための、最初の1回だけの設定。無料。

アプリは Drive 上に `cycle-tracker-data.json` を1つ作り、それだけを読み書きする
（権限は「このアプリが作ったファイルのみ」。Drive の他のファイルは見えない）。

## 手順

1. <https://console.cloud.google.com/> を開き、プロジェクトを新規作成する（名前は何でもよい）。
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を検索し、有効にする。
3. 「API とサービス」→「OAuth 同意画面」を設定する。
   - ユーザーの種類：**外部**
   - アプリ名・サポートメール・デベロッパーの連絡先を入力
   - 公開ステータスが「テスト」の間は、「テストユーザー」に自分の Google アカウントを追加する
4. 「API とサービス」→「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 「承認済みの JavaScript 生成元」に次の2つを追加
     - `https://<GitHubのユーザー名>.github.io`（公開先。パスは付けない）
     - `http://localhost:5173`（PC で開発用に動かす場合）
   - 「承認済みのリダイレクト URI」は空のままでよい
5. 発行された **クライアント ID**（`….apps.googleusercontent.com`）をコピーする。
   クライアント シークレットは使わない。
6. アプリの「設定」→「Google Drive と同期」にクライアント ID を貼り、
   「Google でログインして同期を始める」を押す。
7. 2台目以降の端末でも、同じクライアント ID を貼って同じ Google アカウントでログインする。

## 動き方

- 記録はまず端末の中に保存され、数秒後に Drive と同期される。オフラインでも入力できる。
- 同じ記録を2台で直した場合は、後から保存した方が残る。
- Google のログインは約1時間で切れる。切れているときはホームに「Drive 未同期」と出るので、
  「今すぐ同期」を押す（多くの場合、確認画面は一瞬で閉じる）。
- 「同期を止める」「この端末の記録を全消去」をしても、Drive 上のファイルは消えない。
  完全に消すときは Drive で `cycle-tracker-data.json` を削除する。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| `origin_mismatch` / `invalid_request` | 手順4の「JavaScript 生成元」が、アプリを開いている URL の先頭部分と一致しているか |
| `access_denied` | 手順3でテストユーザーに自分のアカウントを追加したか |
| ポップアップがブロックされた | ブラウザでこのサイトのポップアップを許可する |
| Drive API 403 | 手順2で Drive API を有効にしたか |
